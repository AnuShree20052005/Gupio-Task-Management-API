# Gupio Task Management API

A RESTful Task Management API built using Flask and SQLite.

## Features

- Create a task
- Get all tasks
- Get a task by ID
- Update a task
- Delete a task
- Search tasks
- Filter tasks by status
- Filter tasks by priority
- Input validation
- Error handling

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- Flask-CORS
- Gunicorn
- Postman
